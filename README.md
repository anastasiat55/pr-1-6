# Архів практичних робіт з TypeScript

Цей репозиторій містить повний архів 6 практичних робіт з TypeScript:

- Практична 1: базові типи (string, number, boolean)
- Практична 2: інтерактивність (модальні вікна, scroll, fetch)
- Практична 3: система розкладу занять
- Практична 4: модулі та типи (реалізовано в одному файлі)
- Практична 5: інтернет-магазин з типами товарів
- Практична 6: система управління університетом

## Гілки
- `main` — основна гілка
- `develop` — архів усіх практичних робіт
- `archive` — повний код в одному файлі
- `feature/*` — окремі гілки для кожної практичної

## Запуск
1. Встановити TypeScript:
npm install typescript --save-dev
