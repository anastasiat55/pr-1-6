# Архів практичних робіт з TypeScript

У цьому репозиторії зібрані всі 6 практичних робіт з дисципліни **TypeScript**:
- Практична 1: базові типи
- Практична 2: інтерактивність (модальні вікна, scroll, fetch)
- Практична 3: система розкладу занять
- Практична 4: модулі та типи
- Практична 5: інтернет-магазин
- Практична 6: система управління університетом

Гілки:
- `main` — основна гілка
- `develop` — робоча гілка з архівом усіх практичних
- `feature/*` — окремі гілки для кожної практичної роботи
- `archive` — повний код усіх практичних в одному файлі
